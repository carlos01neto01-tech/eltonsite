# Site do Elton Tarnhovi

Página estática pronta para GitHub Pages. O pacote inclui os arquivos do site na raiz e uma cópia equivalente em `docs/`, para funcionar com qualquer uma das duas origens de publicação.

## Publicar pelo GitHub Pages

1. Extraia o ZIP e envie **todo o conteúdo** para a raiz do repositório, mantendo a pasta `docs/`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch** e selecione `main`.
4. Escolha `/ (root)` se quiser publicar os arquivos da raiz, ou `/docs` se essa for a pasta configurada no Pages. As duas cópias incluem `index.html` e `assets/`.

O site usa as fontes Montaga e Mona Sans pelo Google Fonts, então precisa de conexão com a internet para carregá-las.

Os botões de contato e YouTube estão ligados às seções internas enquanto os links oficiais não forem informados. Depois, substitua os destinos nos links correspondentes do `index.html`.
